# `@pzstudio/cli` 0.42210.2

Stable graduation of the `0.42210.x` line — no functional changes. Built
from the verified `0.42210.1` pre-release content on `release/0.42210.2`
and shipped as the first **bare version on npm `latest`**: semver ranges
like `^0.42210.0` resolve again (the promoted `-next` builds never
satisfied ranges).

## What's changed

### Release-process facts

- Channel parity (even patch = stable): the graduation version is committed
  in both `packages/cli/package.json` and
  `packages/vscode-extension/package.json` and tagged `0.42210.2`.
- The CLI is published with an explicit `--tag latest` override (the
  package's `publishConfig.tag` stays `next` for the routine next-channel
  flow).
- The extension packages `0.42210.2` **without** `--pre-release` — its
  first stable-channel release; stable-channel users auto-update from
  `0.42200.1`.
- Publishing steps are **owner-manual** (owner rule 2026-11-08): agents
  build, pack, smoke, package, tag and verify, and hand the exact commands
  to the owner.
- The release runbook gains the CHANGELOG requirement (every release-prep
  updates the root changelog, the extension changelog, and these
  per-version notes).

## Compatibility

- Identical to `@pzstudio/cli` 0.42210.0: the `@pzstudio/cli/api` exports,
  the root-import rejection, exit codes, the stream contract and `--json`
  are unchanged.
- The VS Code extension **0.42210.2** bundles this engine (marketplace
  stable channel).
