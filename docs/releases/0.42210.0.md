# `@pzstudio/cli` 0.42210.0

Template-current release: `pzstudio update` refreshes the global legacy
template cache, and the project/mod template targets move to Project Zomboid
**42.21.0**. No breaking changes to the JSON contract, the exit-code matrix,
or the stream contract.

## What's changed

### `pzstudio update` refreshes the global legacy template cache

The bundled legacy templates are stamped with the CLI version and build
date. When `pzstudio update` runs and the bundled copy is newer than the
shared cache at `~/.pzstudio/.template-legacy`, the cache is refreshed
automatically — projects created afterward use current templates without a
manual cache wipe.

- The cache stamp is written **only after the copy completes**: an
  interrupted or failed copy leaves the previous stamp and cache intact.
- `pzstudio.forceUpdate` / `--force-update` forces a refresh past the stamp
  check.
- Recovery: delete `~/.pzstudio/.template-legacy` and re-run
  `pzstudio update`.

### PZ 42.21.0 templates

- Vendored `.template-project` / `.template-mod` are pinned to tag `42.21.0`.
- Runtime default project/mod template refs move to `42.21.0` (workshop
  `42.0` and language `42.13.1` unchanged).
- Real-environment CLI-10 expectations align with the 42.21.0 project
  template layout (no `package.json` in new projects).

### Shipped template hygiene

- `.git` gitfiles from the vendored template checkouts are stripped from
  shipped copies.

### Fixed

- Shipped declarations are self-contained again: two internal route-guard
  helpers no longer leak Node's `Dirent` type into the public
  `@pzstudio/cli/api` declaration chain, so TypeScript consumers no longer
  require ambient `@types/node` to compile against the package (regression
  introduced after 0.42200.1 and never published).

### Host fixes

- The extension's DevSync flush no longer breaks when the verbose logger
  sink is absent.
- Extension vsce packaging restored: `@types/vscode` pinned to the engines
  minimum, transitive overrides dropped.

## Compatibility

- `@pzstudio/cli/api` exports are unchanged; the root-import rejection
  (`ERR_PACKAGE_PATH_NOT_EXPORTED`) is unchanged.
- Exit codes, the stream contract and `--json` are unchanged.
- The VS Code extension **0.42210.0** bundles this engine. The legacy
  marketplace listing (`escapepz.pzstudio`) receives the same engine as a
  one-off bridge update **2.242170.1** (its listing content is replaced by
  the pzstudio42 README/CHANGELOG pointing at the new listing).
