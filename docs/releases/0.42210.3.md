# `@pzstudio/cli` 0.42210.3

Usage logging comes to the engine: local, inspectable, shareable — and
never uploaded. The first successful build also surfaces the project
landing page once per machine. No breaking changes to the JSON contract,
the exit-code matrix, or the stream contract.

## What's changed

### Usage logging (local-only)

- One NDJSON event per executed command in `~/.pzstudio/usage/`: command
  name, duration, error code, flag names — never paths or flag values.
  Help/banner invocations (`pzstudio --help`, the bare banner,
  `pzstudio --version`) record nothing — pure invocations stay
  side-effect-free and never scaffold `~/.pzstudio`.
- **On by default**, announced by a one-time notice on first write;
  nothing is ever uploaded — sharing is a manual
  `pzstudio usage export`.
- `pzstudio usage status` inspects the current state, `pzstudio usage off`
  stops recording (`--purge` also deletes the logs), and
  `pzstudio usage export [--out <file>]` bundles the logs into a zip for
  attaching to an issue.
- A process that is already running (for example the VS Code extension)
  keeps logging until it is restarted after `pzstudio usage off`.

### First-build landing-page print

- On standalone runs, the first successful `build` prints the project
  landing-page URL once per machine (standalone gate + marker dotfile;
  embedded/library surfaces are not affected), as a closing note after
  the completion line: `See tips & updates -> <url>`.

### Fixes

- Usage-log final-review minors: the one-time notice is written after the
  event append (a failed write is never announced), the per-machine salt
  file no longer races on Windows, `usage export --out` failures surface
  as `CliError`, and a `projectHash` guard for malformed project layouts.
- Extension-side: the `PZ Studio 42` display name is synced into the
  locale nls tables.

## Compatibility

- `@pzstudio/cli/api` exports are unchanged; the root-import rejection
  (`ERR_PACKAGE_PATH_NOT_EXPORTED`) is unchanged.
- Exit codes, the stream contract and `--json` are unchanged. The
  `usageLog` config section is optional and validated; deleting
  `~/.pzstudio/config.json` resets logging to the default (on).
- The VS Code extension **0.42210.3** (marketplace pre-release channel)
  bundles this engine.
