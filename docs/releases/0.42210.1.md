# `@pzstudio/cli` 0.42210.1

Release-channel re-stamp of the `0.42210.0` content — no functional changes.
This is the first release shipped under the **channel parity** convention
(odd patch = pre-release channel, even patch = stable channel), introduced
after the marketplace burned the bare `0.42210.0` name on its pre-release
channel (a marketplace version can never be re-used across channels).

## What's changed

### Release-process facts

- Built from tag `0.42210.0` on the dedicated `release/0.42210.1` branch —
  the `42.21.0-dev` changes landing after the tag are excluded and ship in
  a later pre-release.
- The CLI is published as a **bare version** (`0.42210.1`, no `-next.<ts>`
  stamp) to npm `latest` — the clean re-stamp of the burned `0.42210.0`
  content, so npm `latest` and the marketplace pre-release share one
  version string.
- The extension uploads `0.42210.1` to the marketplace pre-release channel
  (`vsce --pre-release`).
- The release runbook now codifies channel parity and the graduation flow
  ([`RELEASE.md`](RELEASE.md)).

## Compatibility

- Identical to `@pzstudio/cli` 0.42210.0: the `@pzstudio/cli/api` exports,
  the root-import rejection, exit codes, the stream contract and `--json`
  are unchanged.
- The VS Code extension **0.42210.1** bundles this engine (marketplace
  pre-release channel).
