Deliverable 05 // Monochrome Brand Guidelines & Do / Don't Matrix

GEOMETRIC CONSTRUCTION // CLEAR SPACE // LEGACY DEPRECATION
05.1 // GEOMETRIC CONSTRUCTION 8×8 MODULE GRID
CHAMFER: 45.0° // SEAM: 0.5S

Built on a 256×256 unit canvas subdivided into an 8×8 modular grid (32U per module). Both P and Z maintain an identical stroke weight S, with a negative-space diagonal seam equal to 0.5S.

05.2 // CLEAR SPACE BOUNDARY MINIMUM MARGIN: 1X
1x = P-Counter Height

Maintain an unobstructed clear-space zone of at least 1x around all four sides of the monogram, where x equals the vertical interior counter height of the letter P (or 1× stroke width S for compact UI headers).

05.3 // MINIMUM SCALE THRESHOLDS 16PX / 80PX
STANDALONE ICON MIN: 16 × 16 PX
HORIZONTAL WORDMARK MIN: 80 PX WIDTH
PRIMARY VERTICAL LOCKUP: 96 PX WIDTH

Below 80px horizontal width, omit the STUDIO wordmark and use the standalone PZ monogram icon exclusively to preserve counter clarity.

DO // APPROVED Developer-First Monochromatic Standard
ZED / OPENCODE / ZCODE
  • [+] Use strictly the 6 approved monochromatic tokens (#090A0B through #F8F8F6) across all surfaces.
  • [+] Render the geometric PZ monogram with crisp vector edges, uniform stroke weight, and high-contrast negative space.
  • [+] Frame product surfaces using 1px structural borders (#353A40), technical grids, and restrained uppercase typography.
  • [+] Pair the geometric wordmark with monospace operational metadata (@pzstudio/cli, v0.42210.0).
DON'T // FORBIDDEN Retired Legacy Gaming & Zombie Aesthetics
STRICTLY DEPRECATED
  • [×] No Red Accents (#FF0000): Never use red fills, crimson borders, neon glows, or multi-color gaming gradients.
  • [×] No Zombie Mascots or Gore: Never include zombie illustrations, blood drips, scratches, or distressed grunge textures.
  • [×] No Pixel-Art Jagged Edges: Never use 8-bit staircase pixelation or crumbling voxel fragments on the P or Z glyphs.
  • [×] No Redundant </> Clip-Art: Never append generic code bracket icons next to the monogram or apply 3D bevels/drop shadows.
